# Contributing to awesome-ai-apps

Thanks for helping keep **awesome-ai-apps** curated, lean, and genuinely useful. The list is deliberately small: **127 hand-picked AI apps across 10 categories** — only apps that genuinely stand out.

## Before you start

**Please star this repository** ⭐ before submitting a pull request. We ask all contributors to star the project as a sign of support and to help it reach more people in the community. This is required for your PR to be merged.

## What we accept

- **New AI apps or tools** missing from the list that meet the quality bar.
- **Corrections** to existing entries (broken links, outdated descriptions, wrong category).
- **Category suggestions** when a new app doesn't fit an existing category.

We do **not** accept:
- Spam, duplicate, or affiliate links.
- Self-promotional entries without a real, working product.
- Dead links or apps that have clearly been abandoned.
- Apps already on the list (check first!).

## Entry format

Every entry is a single line in this exact format:

```markdown
- **[App Name](https://official-url.com/)**: One-line description of what it does and why it stands out.
```

Rules:

1. **Alphabetical order** — insert the new entry in the correct alphabetical spot within its category (ignoring case; e.g. *DeepSeek* comes before *Gemini*).
2. **Verified link** — the URL must point to the app's official site or primary repository. Test it before submitting.
3. **One line, one description** — keep it short, factual, and non-promotional. No marketing hype, no emoji, no bolded claims beyond the name.
4. **The 10 categories** are:

   | # | Category |
   |---|----------|
   | 1 | AI Chatbots |
   | 2 | AI Coding |
   | 3 | AI Search & Research |
   | 4 | AI Writing |
   | 5 | AI Image |
   | 6 | AI Video |
   | 7 | AI Audio & Voice |
   | 8 | AI Productivity & Knowledge |
   | 9 | AI Automation & Agents |
   | 10 | Local & Open Source |

   Place the entry in the category that best matches its primary function. If you're unsure, open an issue and ask before editing.

5. **No URL shorteners**, no tracking parameters (`?utm_*`, `ref=`), no referral codes.
6. When you add an entry, update the **"Total: N AI apps across 10 categories"** line in the README header by +1.

## Before you submit

- [ ] **Starred the repository** (required for PR merge).
- [ ] Read the README and confirm the app isn't already listed (search by name and alias).
- [ ] Verify the link works and points to the official product.
- [ ] Confirm the description is accurate, one line, and matches the existing tone.
- [ ] Confirm alphabetical placement and correct category.
- [ ] Updated the total count in the README header (if adding an app).
- [ ] No spam, self-promo, or affiliate links.

## Workflow

1. Fork the repository.
2. Create a feature branch: `git checkout -b add/app-name` or `git checkout -b fix/description`.
3. Make your edit to `README.md`.
4. Commit with a clear message, e.g. `Add <App Name> to <Category>` or `Fix broken link for <App Name>`.
5. Push and open a pull request against `main`.
6. Fill in the pull request template (title, category, app name, one-line description, link).

**Prefer an issue?** If you're not comfortable editing the README, open an [app submission issue](.github/ISSUE_TEMPLATE/add_app.md) instead and a maintainer (or another contributor) will pick it up.

## Review & merge

- **All PR authors must have starred the repository.** Maintainers will verify this before merging.
- Maintainers verify every link and description before merging.
- PRs that add spam, self-promo, broken links, or out-of-order entries will be closed with a comment.
- We aim to review submissions within a few days.

## Questions

Open an issue or start a discussion. Thanks for contributing to a leaner, better AI list.
