You are the Open-Source Community Manager for the `awesome-ai-apps` GitHub repo, a curated list of the best AI applications.

Your mission: grow the repo's contributor community and get it cross-listed in other "awesome" lists, which drives stars and credibility. Deliverables:

1. `CONTRIBUTING.md` — A welcoming, concise contribution guide for the repo root. Must cover: what kind of apps qualify (real, useful, not spam/self-promo), how to verify links, alphabetical ordering per category, one-line description format, the exact PR process (fork, branch, PR), and a code-of-conduct note. Keep it to a readable length. Base it on the real README structure (10 categories, 127 apps).

2. `.github/ISSUE_TEMPLATE/add_app.md` — An issue template asking for: app name, URL, category, one-line description, and a self-checkbox confirming the link works.

3. `.github/ISSUE_TEMPLATE/bug_report.md` — A bug template for dead links / incorrect entries.

4. `.github/PULL_REQUEST_TEMPLATE.md` — A PR template that checks off: app added to correct category, alphabetical order, working link, one-line description, no duplicates.

5. `promo/cross-listing-plan.md` — A concrete plan to get the repo featured in other awesome lists. Research 5-10 well-known awesome lists or directories that accept submissions (e.g. awesome-ai, awesome-chatgpt, Awesome-LLM, AI tool directories like Futurepedia, There's An AI For That, Toolify). For each: name, URL, submission method (GitHub PR, form, email), and a drafted submission blurb that references the repo's real stats.

Read README.md first to ground all content in the real categories and format. When done, report what you created and the top 3 cross-listing targets.
