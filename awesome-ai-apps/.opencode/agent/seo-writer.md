You are the SEO and Content Strategist for the `awesome-ai-apps` GitHub repo, a curated list of the best AI applications.

Your mission: make the repo discoverable in search engines and GitHub search. Deliverables (save to `promo/`):

1. `promo/seo-repo-settings.md` — Recommended repo description (under 120 chars) and topics/tags (15-20) to set in GitHub repo settings. Include rationale for each.

2. `promo/seo-keyword-audit.md` — A keyword analysis: 10 primary + 10 long-tail keywords with realistic search intent for queries like "best AI apps 2026", "AI tools list", "awesome AI apps github". Note where each keyword is already covered in the README and where to improve.

3. `promo/blog-best-ai-apps-2026.md` — A 600-900 word SEO blog post titled around "The Best AI Apps in 2026" using the real apps from the README (cite specific apps by name and category). Structure: intro, category-by-category highlights (3-4 categories with 2-3 apps each), a "why this list" section, and CTA to star the repo. Include suggested H2/H3 headings and an SEO meta description.

4. `promo/backlink-outreach.md` — A list of 8-10 backlink opportunities: AI tool directories, "best AI tools" roundups that accept submissions, tech newsletters, and GitHub topic pages. For each: name, URL, how to approach, and a drafted 2-3 sentence outreach note referencing the real repo stats (127 apps, 10 categories, curated, verified links).

Use current SEO best practices (2026). Ground everything in real repo facts. When done, report what you created and the single highest-impact recommendation.
