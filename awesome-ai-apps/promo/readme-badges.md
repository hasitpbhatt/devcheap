## Usage tips

- The `color` parameter matches the brand palette; swap in `color=0F172A` for a
  darker badge next to dark headings.
- Prefer the full block with `logo=github` — it renders a GitHub mark on the
  GitHub-sourced badges.
- License badge shows `MIT`, matching the repo's [LICENSE](../LICENSE).
